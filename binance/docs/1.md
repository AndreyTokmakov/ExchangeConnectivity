Да. Для первого MVP я бы уже сделал **полный рабочий vertical slice**:

```text
Binance Testnet
      │
      ├── REST /api/v3/depth
      │       │
      │       ▼
      │   Snapshot
      │
      └── WebSocket @depth
              │
              ▼
        DepthUpdate stream
              │
              ▼
      sequence synchronization
              │
              ▼
          OrderBook
              │
              ▼
       MarketUpdate callback
```

Для Spot Testnet используем:

* REST: `https://testnet.binance.vision/api/v3/depth`
* WebSocket: `wss://stream.testnet.binance.vision:9443/ws/<symbol>@depth`

Это соответствует Binance Spot Testnet market-data API. ([developers.binance.com][1])

Ниже — именно **первый MVP**, без order entry/authentication. Он умеет:

* подключиться к Binance Testnet;
* получить REST snapshot;
* подключиться к `@depth`;
* буферизовать WebSocket updates;
* синхронизировать snapshot + updates;
* проверять sequence;
* детектировать gap;
* поддерживать локальный order book;
* выдавать normalized `MarketUpdate`;
* переподключаться после ошибки.

# 4. `src/market_data/order_book.cpp`

```cpp
#include "market_data/order_book.hpp"

namespace trading::market_data
{
    void OrderBook::applySnapshot(const OrderBookLevels& bids,
                                  const OrderBookLevels& asks,
                                  SequenceNumber lastUpdateId)
    {
        bids_ = bids;
        asks_ = asks;
        sequence_ = lastUpdateId;
    }

    bool OrderBook::applyUpdate(const MarketUpdate& update) noexcept
    {
        if (update.firstUpdateId > sequence_ + 1)
        {
            return false;
        }

        if (update.lastUpdateId <= sequence_)
        {
            return true;
        }

        for (const PriceLevelUpdate& level : update.bids)
        {
            if (level.quantity == 0)
            {
                bids_.erase(level.price);
            }
            else
            {
                bids_[level.price] = level.quantity;
            }
        }

        for (const PriceLevelUpdate& level : update.asks)
        {
            if (level.quantity == 0)
            {
                asks_.erase(level.price);
            }
            else
            {
                asks_[level.price] = level.quantity;
            }
        }

        sequence_ = update.lastUpdateId;

        return true;
    }

    OrderBook::Price OrderBook::bestBid() const noexcept
    {
        return bids_.empty() ? Price {} : bids_.rbegin()->first;
    }

    OrderBook::Price OrderBook::bestAsk() const noexcept
    {
        return asks_.empty() ? Price {} : asks_.begin()->first;
    }

    OrderBook::SequenceNumber OrderBook::sequence() const noexcept
    {
        return sequence_;
    }

    const OrderBookLevels& OrderBook::bids() const noexcept
    {
        return bids_;
    }

    const OrderBookLevels& OrderBook::asks() const noexcept
    {
        return asks_;
    }

    void OrderBook::clear() noexcept
    {
        bids_.clear();
        asks_.clear();
        sequence_ = 0;
    }
}
```

# 7. `src/exchange/binance/binance_market_data_parser.cpp`

Здесь я намеренно **не использую `double`**.

Binance присылает цены и quantities как decimal strings. Мы преобразуем их в fixed-point integer.

Для MVP:

```text
1 unit = 100'000'000 ticks
```

то есть:

```text
16418.50
```

становится:

```text
1641850000000
```

```cpp
#include "exchange/binance/binance_market_data_parser.hpp"

#include <simdjson.h>

#include <stdexcept>

namespace exchange::binance
{
    namespace
    {
        constexpr std::int64_t DecimalScale = 100'000'000;

        std::int64_t parseDecimal(std::string_view value)
        {
            bool negative = false;
            std::size_t index = 0;

            if (!value.empty() && value.front() == '-')
            {
                negative = true;
                index = 1;
            }

            std::int64_t integerPart = 0;

            while (index < value.size() && value[index] != '.')
            {
                integerPart =
                    integerPart * 10 +
                    static_cast<std::int64_t>(value[index] - '0');

                ++index;
            }

            std::int64_t fractionalPart = 0;
            std::size_t fractionalDigits = 0;

            if (index < value.size() && value[index] == '.')
            {
                ++index;

                while (index < value.size() && fractionalDigits < 8)
                {
                    fractionalPart =
                        fractionalPart * 10 +
                        static_cast<std::int64_t>(value[index] - '0');

                    ++fractionalDigits;
                    ++index;
                }
            }

            while (fractionalDigits < 8)
            {
                fractionalPart *= 10;
                ++fractionalDigits;
            }

            const std::int64_t result =
                integerPart * DecimalScale + fractionalPart;

            return negative ? -result : result;
        }
    }

    DepthUpdate BinanceMarketDataParser::parseDepthUpdate(
        std::string_view message) const
    {
        simdjson::dom::parser parser;

        const simdjson::dom::element document =
            parser.parse(message.data(), message.size());

        DepthUpdate update;

        update.exchangeTimestamp =
            static_cast<Timestamp>(
                document["E"].get_uint64());

        update.firstUpdateId =
            static_cast<SequenceNumber>(
                document["U"].get_uint64());

        update.lastUpdateId =
            static_cast<SequenceNumber>(
                document["u"].get_uint64());

        const simdjson::dom::array bids =
            document["b"].get_array();

        for (const simdjson::dom::element level : bids)
        {
            const simdjson::dom::array values =
                level.get_array();

            const std::string_view price =
                values.at(0).get_string();

            const std::string_view quantity =
                values.at(1).get_string();

            update.bids.emplace_back(
                parsePrice(price),
                parseQuantity(quantity));
        }

        const simdjson::dom::array asks =
            document["a"].get_array();

        for (const simdjson::dom::element level : asks)
        {
            const simdjson::dom::array values =
                level.get_array();

            const std::string_view price =
                values.at(0).get_string();

            const std::string_view quantity =
                values.at(1).get_string();

            update.asks.emplace_back(
                parsePrice(price),
                parseQuantity(quantity));
        }

        return update;
    }

    trading::market_data::MarketUpdate
    BinanceMarketDataParser::normalize(const DepthUpdate& update) const
    {
        trading::market_data::MarketUpdate result;

        result.firstUpdateId = update.firstUpdateId;
        result.lastUpdateId = update.lastUpdateId;
        result.exchangeTimestamp = update.exchangeTimestamp;

        result.bids.reserve(update.bids.size());
        result.asks.reserve(update.asks.size());

        for (const auto& [price, quantity] : update.bids)
        {
            result.bids.push_back({price, quantity});
        }

        for (const auto& [price, quantity] : update.asks)
        {
            result.asks.push_back({price, quantity});
        }

        return result;
    }

    Price BinanceMarketDataParser::parsePrice(
        std::string_view value)
    {
        return parseDecimal(value);
    }

    Quantity BinanceMarketDataParser::parseQuantity(
        std::string_view value)
    {
        return parseDecimal(value);
    }
}
```

# 9. `src/exchange/binance/binance_rest_client.cpp`

Для snapshot REST используется отдельное HTTPS-соединение. Для MVP это нормально: snapshot нужен только при initialization/recovery, а hot path идёт через WebSocket.

```cpp
#include "exchange/binance/binance_rest_client.hpp"
#include "exchange/binance/binance_market_data_parser.hpp"

#include <boost/asio/connect.hpp>
#include <boost/asio/ip/tcp.hpp>
#include <boost/asio/ssl.hpp>
#include <boost/beast/core.hpp>
#include <boost/beast/http.hpp>
#include <boost/beast/ssl.hpp>

#include <simdjson.h>

#include <sstream>
#include <stdexcept>

namespace exchange::binance
{
    BinanceRestClient::BinanceRestClient(std::string host)
        : host_(std::move(host))
    {
    }

    DepthSnapshot BinanceRestClient::getDepthSnapshot(
        const std::string& symbol,
        std::size_t limit) const
    {
        boost::asio::io_context ioContext;

        boost::asio::ssl::context sslContext{
            boost::asio::ssl::context::tls_client
        };

        sslContext.set_default_verify_paths();
        sslContext.set_verify_mode(
            boost::asio::ssl::verify_peer);

        boost::asio::ip::tcp::resolver resolver{ioContext};

        const boost::asio::ip::tcp::resolver::results_type endpoints =
            resolver.resolve(host_, "443");

        boost::beast::ssl_stream<
            boost::beast::tcp_stream> stream{ioContext, sslContext};

        boost::asio::connect(
            stream.next_layer().socket(),
            endpoints.begin(),
            endpoints.end());

        if (!SSL_set_tlsext_host_name(
                stream.native_handle(),
                host_.c_str()))
        {
            throw std::runtime_error{
                "Failed to set TLS server name"
            };
        }

        stream.handshake(
            boost::asio::ssl::stream_base::client);

        std::ostringstream target;
        target << "/api/v3/depth"
               << "?symbol=" << symbol
               << "&limit=" << limit;

        boost::beast::http::request<
            boost::beast::http::string_body> request{
                boost::beast::http::verb::get,
                target.str(),
                11
            };

        request.set(
            boost::beast::http::field::host,
            host_);

        request.set(
            boost::beast::http::field::user_agent,
            "hft-binance-connector/1.0");

        boost::beast::http::write(stream, request);

        boost::beast::flat_buffer buffer;

        boost::beast::http::response<
            boost::beast::http::string_body> response;

        boost::beast::http::read(
            stream,
            buffer,
            response);

        if (response.result() !=
            boost::beast::http::status::ok)
        {
            throw std::runtime_error{
                "Binance REST request failed: " +
                std::to_string(
                    response.result_int())
            };
        }

        boost::beast::error_code shutdownError;

        stream.shutdown(shutdownError);

        simdjson::dom::parser parser;

        const simdjson::dom::element document =
            parser.parse(
                response.body().data(),
                response.body().size());

        DepthSnapshot snapshot;

        snapshot.lastUpdateId =
            static_cast<SequenceNumber>(
                document["lastUpdateId"].get_uint64());

        BinanceMarketDataParser marketDataParser;

        const simdjson::dom::array bids =
            document["bids"].get_array();

        for (const simdjson::dom::element level : bids)
        {
            const simdjson::dom::array values =
                level.get_array();

            const std::string_view price =
                values.at(0).get_string();

            const std::string_view quantity =
                values.at(1).get_string();

            snapshot.bids.emplace(
                BinanceMarketDataParser::parsePrice(price),
                BinanceMarketDataParser::parseQuantity(quantity));
        }

        const simdjson::dom::array asks =
            document["asks"].get_array();

        for (const simdjson::dom::element level : asks)
        {
            const simdjson::dom::array values =
                level.get_array();

            const std::string_view price =
                values.at(0).get_string();

            const std::string_view quantity =
                values.at(1).get_string();

            snapshot.asks.emplace(
                BinanceMarketDataParser::parsePrice(price),
                BinanceMarketDataParser::parseQuantity(quantity));
        }

        return snapshot;
    }
```

```cpp
#include "exchange/binance/binance_web_socket_client.hpp"

#include <boost/asio/connect.hpp>
#include <boost/beast/core.hpp>

#include <openssl/ssl.h>

namespace exchange::binance
{
    BinanceWebSocketClient::BinanceWebSocketClient(
        boost::asio::io_context& ioContext,
        boost::asio::ssl::context& sslContext,
        MessageHandler messageHandler)
        : resolver_(boost::asio::make_strand(ioContext))
        , webSocket_(
              boost::asio::make_strand(ioContext),
              sslContext)
        , messageHandler_(std::move(messageHandler))
    {
        webSocket_.control_callback(
            [this](boost::beast::websocket::frame_type frameType,
                   boost::beast::string_view)
            {
                if (frameType ==
                    boost::beast::websocket::frame_type::ping)
                {
                    webSocket_.pong({});
                }
            });
    }

    void BinanceWebSocketClient::connect(
        const std::string& host,
        const std::string& port,
        const std::string& target)
    {
        host_ = host;
        target_ = target;

        resolver_.async_resolve(
            host,
            port,
            [this](
                boost::beast::error_code errorCode,
                boost::asio::ip::tcp::resolver::results_type results)
            {
                onResolve(errorCode, std::move(results));
            });
    }

    void BinanceWebSocketClient::onResolve(
        boost::beast::error_code errorCode,
        boost::asio::ip::tcp::resolver::results_type results)
    {
        if (errorCode)
        {
            return;
        }

        boost::asio::async_connect(
            webSocket_.next_layer().next_layer(),
            results.begin(),
            results.end(),
            [this](
                boost::beast::error_code errorCode,
                const boost::asio::ip::tcp::endpoint&)
            {
                onConnect(errorCode);
            });
    }

    void BinanceWebSocketClient::onConnect(
        boost::beast::error_code errorCode)
    {
        if (errorCode)
        {
            return;
        }

        if (!SSL_set_tlsext_host_name(
                webSocket_.next_layer().native_handle(),
                host_.c_str()))
        {
            return;
        }

        webSocket_.next_layer().async_handshake(
            boost::asio::ssl::stream_base::client,
            [this](boost::beast::error_code errorCode)
            {
                onSslHandshake(errorCode);
            });
    }

    void BinanceWebSocketClient::onSslHandshake(
        boost::beast::error_code errorCode)
    {
        if (errorCode)
        {
            return;
        }

        webSocket_.async_handshake(
            host_,
            target_,
            [this](boost::beast::error_code errorCode)
            {
                onWebSocketHandshake(errorCode);
            });
    }

    void BinanceWebSocketClient::onWebSocketHandshake(
        boost::beast::error_code errorCode)
    {
        if (errorCode)
        {
            return;
        }

        read();
    }

    void BinanceWebSocketClient::read()
    {
        webSocket_.async_read(
            readBuffer_,
            [this](
                boost::beast::error_code errorCode,
                std::size_t bytesTransferred)
            {
                onRead(errorCode, bytesTransferred);
            });
    }

    void BinanceWebSocketClient::onRead(
        boost::beast::error_code errorCode,
        std::size_t)
    {
        if (errorCode)
        {
            onClose(errorCode);
            return;
        }

        const boost::beast::flat_buffer::const_buffers_type data =
            readBuffer_.data();

        const std::string_view message{
            static_cast<const char*>(data.data()),
            readBuffer_.size()
        };

        messageHandler_(message);

        readBuffer_.consume(readBuffer_.size());

        read();
    }

    void BinanceWebSocketClient::close()
    {
        boost::beast::error_code errorCode;

        webSocket_.close(
            boost::beast::websocket::close_code::normal,
            errorCode);
    }

    void BinanceWebSocketClient::onClose(
        boost::beast::error_code)
    {
    }
}
```

```cpp
        , reconnectTimer_(ioContext)
        , restClient_(std::string{RestHost})
        , webSocket_(
              ioContext,
              sslContext,
              [this](std::string_view message)
              {
                  onWebSocketMessage(message);
              })
        , symbol_(std::move(symbol))
        , marketUpdateHandler_(std::move(marketUpdateHandler))
    {
    }

    void BinanceMarketDataConnector::start()
    {
        startWebSocket();
    }

    void BinanceMarketDataConnector::startWebSocket()
    {
        synchronized_ = false;

        const std::string target =
            "/ws/" + symbol_ + "@depth";

        webSocket_.connect(
            std::string{WebSocketHost},
            "9443",
            target);
    }

    void BinanceMarketDataConnector::onWebSocketMessage(
        std::string_view message)
    {
        const DepthUpdate update =
            parser_.parseDepthUpdate(message);

        if (!synchronized_)
        {
            synchronize();

            return;
        }

        const trading::market_data::MarketUpdate marketUpdate =
            parser_.normalize(update);

        if (!orderBook_.applyUpdate(marketUpdate))
        {
            std::cerr
                << "Order book sequence gap detected. "
                << "Expected: "
                << orderBook_.sequence() + 1
                << ", received: "
                << marketUpdate.firstUpdateId
                << '\n';

            synchronized_ = false;

            scheduleReconnect();

            return;
        }

        publish(marketUpdate);
    }

    void BinanceMarketDataConnector::synchronize()
    {
        try
        {
            const DepthSnapshot snapshot =
                restClient_.getDepthSnapshot(
                    symbol_,
                    SnapshotLimit);

            orderBook_.applySnapshot(
                snapshot.bids,
                snapshot.asks,
                snapshot.lastUpdateId);

            synchronized_ = true;

            std::cout
                << "Order book synchronized. "
                << "Sequence: "
                << orderBook_.sequence()
                << '\n';
        }
        catch (const std::exception& exception)
        {
            std::cerr
                << "Snapshot synchronization failed: "
                << exception.what()
                << '\n';

            scheduleReconnect();
        }
    }

    void BinanceMarketDataConnector::publish(
        const trading::market_data::MarketUpdate& update)
    {
        if (marketUpdateHandler_)
        {
            marketUpdateHandler_(update);
        }
    }

    void BinanceMarketDataConnector::scheduleReconnect()
    {
        synchronized_ = false;

        reconnectTimer_.expires_after(
            ReconnectDelay);

        reconnectTimer_.async_wait(
            [this](const boost::system::error_code& errorCode)
            {
                if (errorCode)
                {
                    return;
                }

                startWebSocket();
            });
    }
}
```

## Но здесь есть важный нюанс

Этот код показывает **архитектуру MVP**, но в текущем варианте есть тонкость с synchronization:

```text
WebSocket
   │
   ├── update 100
   ├── update 101
   ├── update 102
   │
   ▼
REST snapshot
   │
   ▼
lastUpdateId = 101
```

Нельзя просто взять последний WebSocket update после получения snapshot.

Нужно:

```text
WebSocket
    │
    ├── buffer updates
    │
    │       REST Snapshot
    │            │
    │            ▼
    │       lastUpdateId
    │            │
    └────────────┘
             │
             ▼
    найти первый update,
    который пересекает snapshot
             │
             ▼
          OrderBook
```

Именно поэтому **следующая версия этого MVP должна добавить `DepthUpdateBuffer`**.

## Но я бы сейчас не называл это production-ready

Для **первого MVP** структура правильная, но я вижу несколько вещей, которые обязательно надо исправить следующим шагом.

### 1. Snapshot synchronization

Сейчас:

```text
WS → message
       ↓
   synchronize()
       ↓
REST snapshot
```

Это недостаточно корректно.

Нужно:

```text
              ┌───────────────┐
              │ WebSocket     │
              │ updates       │
              └───────┬───────┘
                      │
                      ▼
                UpdateBuffer
                      │
                      │
REST Snapshot ────────┤
                      ▼
              sequence matching
                      │
                      ▼
                  OrderBook
```

### 2. Reconnect

Сейчас reconnect слишком примитивный:

```cpp
scheduleReconnect();
```

Нужно различать:

```text
ConnectionFailed
ConnectionClosed
ReadError
SequenceGap
SnapshotError
```

и иметь state machine:

```text
Disconnected
     │
     ▼
Connecting
     │
     ▼
Buffering
     │
     ▼
Synchronizing
     │
     ▼
Live
     │
     ├── sequence gap ──► Synchronizing
     │
     └── disconnect ────► Connecting
```

### 3. `std::map`

Для первого MVP `std::map` абсолютно нормально.

Но в твоём HFT контексте это место потом стоит отдельно исследовать:

```text
std::map
```

против:

```text
flat_map
sorted vector
custom price-level array
dense price ladder
```

Особенно если instrument имеет ограниченный tick range.

### 4. REST client

REST сейчас synchronous:

```cpp
getDepthSnapshot()
```

Для snapshot/recovery это приемлемо.

Но я бы не смешивал его с market-data hot path.

### 5. Parser allocations

Вот это:

```cpp
std::vector<PriceLevelUpdate>
```

и:

```cpp
emplace_back()
```

создаёт allocations.

Для первого MVP нормально.

Для HFT дальше хочется:

```text
WebSocket buffer
      ↓
parser
      ↓
preallocated MarketUpdate
      ↓
OrderBook
```

с минимальным количеством allocation.

### Самое важное изменение, которое я бы сделал следующим

Я бы **не стал сейчас добавлять ещё functionality**. Лучше сначала довести этот MVP до правильной HFT-архитектуры:

```text
BinanceWebSocketClient
        │
        │ raw message
        ▼
BinanceMarketDataParser
        │
        │ DepthUpdate
        ▼
DepthUpdateBuffer
        │
        ├──────────────┐
        │              │
        ▼              ▼
REST Snapshot    sequence logic
        │              │
        └───────┬──────┘
                ▼
            OrderBook
                │
                ▼
          MarketUpdate
```

И отдельно убрать из `BinanceMarketDataConnector` логику synchronization, чтобы он был **orchestrator**, а не делал всё сам.

Это даст очень хороший фундамент для дальнейшего добавления `@trade`, `aggTrade`, execution/user-data stream и order entry.
